## Purpose

定义水浒卡卡组、人物资料、编号、图片资源和跨卡组查询的统一行为，为单卡鉴赏与多卡对比提供稳定且可复用的数据基础。

## Requirements

### Requirement: 提供四类卡组目录

系统 MUST 按普卡、奖闪、冷烫、立绘的固定顺序提供卡组，并使用稳定的卡组标识 `standard`、`flash_prize`、`code_perm`、`character_art`。

#### Scenario: 读取完整卡组目录

- **WHEN** 页面读取卡组目录
- **THEN** 系统依次返回普卡、奖闪、冷烫和立绘四类卡组
- **AND** 普卡包含 114 张卡、奖闪包含 110 张卡、冷烫包含 145 张卡、立绘包含 115 张卡

### Requirement: 维护卡片领域资料

系统 MUST 为每张卡提供稳定 ID、展示编号、人物名、拼音名、人物介绍和图片描述，并按人物类型提供绰号与星号或身份与系列字段。

#### Scenario: 读取好汉卡资料

- **WHEN** 调用方读取一张好汉卡
- **THEN** 卡片包含人物绰号和星号
- **AND** 卡片不依赖恶人专用字段才能完成展示

#### Scenario: 读取恶人卡资料

- **WHEN** 调用方读取一张 `kind` 为 `villain` 的卡片
- **THEN** 卡片包含身份和系列
- **AND** 系列显示为“六大恶人”或该卡片明确配置的系列

### Requirement: 生成稳定编号和业务展示编号

系统 MUST 将普通数值编号规范化为三位数字字符串，并允许异画、特卡、赠卡和恶人卡使用独立的业务展示前缀。

#### Scenario: 生成普通卡编号

- **WHEN** 卡片数值编号为 `1`
- **THEN** 系统生成稳定 ID `001`
- **AND** 未覆盖展示编号时显示 `001`

#### Scenario: 生成扩展卡展示编号

- **WHEN** 系统生成异画、特卡、赠卡或恶人卡
- **THEN** 展示编号分别可以使用“异NN”“特NN”“赠NN”或“恶NN”格式
- **AND** 稳定 ID 仍使用对应图片资源的数字编号

### Requirement: 使用部署基础路径生成图片地址

系统 MUST 基于 `import.meta.env.BASE_URL` 生成 `public/assets/<卡组目录>/<编号>.<扩展名>` 对应的运行时图片地址，并为卡片关联裁切布局名称。

#### Scenario: 部署在 GitHub Pages 子路径

- **WHEN** 应用基础路径为 `/water-card/`
- **THEN** 卡片图片地址以 `/water-card/assets/` 开头

#### Scenario: 部署在站点根路径

- **WHEN** 应用基础路径为 `/`
- **THEN** 卡片图片地址以 `/assets/` 开头

### Requirement: 统一解释正反面合并图布局

系统 MUST 从集中式布局配置读取卡片正面与背面的裁切参数，并在布局名称无效时回退到普卡布局。

#### Scenario: 读取左右等分卡图

- **WHEN** 卡片布局为奖闪、冷烫或立绘
- **THEN** 系统将图片左半部分解释为正面
- **AND** 将图片右半部分解释为背面

#### Scenario: 读取未知布局

- **WHEN** 调用方请求未配置的布局名称
- **THEN** 系统返回普卡布局而不是中断卡片展示

### Requirement: 区分可回退选择和精确查询

系统 MUST 为页面展示提供带回退的选择解析，并为稳定键和对比状态提供不回退的精确查询。

#### Scenario: 页面选择标识无效

- **WHEN** 页面请求不存在的卡组或当前卡组中不存在的卡片
- **THEN** 系统回退到首个可用卡组或当前卡组的第一张卡

#### Scenario: 对比稳定键失效

- **WHEN** 对比区精确查询不存在的卡组或卡片
- **THEN** 系统返回未找到结果
- **AND** 不得将失效键静默映射到第一张卡

### Requirement: 按人物名查询跨卡组版本

系统 MUST 按卡组注册顺序查询指定人物在各卡组中的版本，并在单一卡组存在多个同名版本时只返回第一个匹配项。

#### Scenario: 人物存在于多个卡组

- **WHEN** 调用方按人物名查询跨卡组版本
- **THEN** 系统返回每个包含该人物的卡组中的第一张同名卡
- **AND** 结果保持卡组注册顺序

#### Scenario: 人物在某卡组中缺失

- **WHEN** 指定人物未收录于某个卡组
- **THEN** 结果跳过该卡组
