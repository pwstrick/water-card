## Purpose

定义鉴赏区和对比区共用的人物选择器、中文与拼音搜索、键盘导航、禁用项处理，以及桌面和移动设备上的焦点管理行为。

## Requirements

### Requirement: 展示当前人物摘要

系统 MUST 在人物选择器触发按钮中展示当前卡片的编号、绰号或身份、人物名和可选版本名。

#### Scenario: 当前卡片包含版本名

- **WHEN** 人物选择器显示一张带 `edition` 的卡片
- **THEN** 触发按钮同时显示展示编号、人物摘要和版本名

### Requirement: 支持多字段人物搜索

系统 MUST 支持按卡片 ID、展示编号、人物名、绰号、身份、版本、星号、系列、完整拼音和拼音首字母进行不区分大小写的包含搜索，并忽略查询中的空白。

#### Scenario: 使用完整拼音搜索

- **WHEN** 用户输入 `wusong`
- **THEN** 结果包含拼音名为 `WU SONG` 的武松

#### Scenario: 使用拼音首字母搜索

- **WHEN** 用户输入 `ws`
- **THEN** 结果包含拼音名为 `WU SONG` 的武松

#### Scenario: 使用中文业务字段搜索

- **WHEN** 用户输入人物名、绰号、身份或版本中的连续文本
- **THEN** 列表只保留搜索语料包含该文本的卡片

#### Scenario: 没有匹配人物

- **WHEN** 查询条件未匹配任何卡片
- **THEN** 面板显示“没有匹配人物”

### Requirement: 提供循环键盘导航

系统 MUST 支持使用上下方向键、Home 和 End 在搜索结果中导航，并通过 roving tabindex 保持单个活动选项可聚焦。

#### Scenario: 使用上下方向键

- **WHEN** 用户在触发按钮、搜索框或选项列表中按下上或下方向键
- **THEN** 焦点按对应方向移动到下一个可用选项
- **AND** 到达边界后从另一端继续

#### Scenario: 使用 Home 或 End

- **WHEN** 用户按下 Home 或 End
- **THEN** 焦点移动到首个或末个可用选项

#### Scenario: 导航经过禁用项

- **WHEN** 方向键路径中存在禁用卡片
- **THEN** 系统跳过禁用卡片并聚焦下一张可用卡片

### Requirement: 支持键盘选择与关闭

系统 MUST 允许用户使用 Enter 或空格选择活动选项，使用 Escape 关闭并恢复触发按钮焦点，并在从选项列表按 Tab 离开时关闭面板。

#### Scenario: 单选模式确认人物

- **WHEN** 用户在活动选项上按 Enter 或空格
- **THEN** 系统选择该人物、关闭面板并恢复触发按钮焦点

#### Scenario: 使用 Escape 关闭

- **WHEN** 人物面板打开且用户按下 Escape
- **THEN** 系统关闭面板、清空查询并恢复触发按钮焦点

#### Scenario: 使用 Tab 离开列表

- **WHEN** 焦点位于选项列表且用户按下 Tab
- **THEN** 系统关闭面板且不阻止正常焦点移动

### Requirement: 处理外部点击和搜索重置

系统 MUST 在用户点击选择器和面板以外区域时关闭面板，并在每次关闭或重新打开时清空之前的搜索条件。

#### Scenario: 点击面板外部

- **WHEN** 人物面板打开且用户在触发器和面板之外按下指针
- **THEN** 系统关闭人物面板

#### Scenario: 关闭后重新打开

- **WHEN** 用户在搜索后关闭并再次打开面板
- **THEN** 系统显示当前卡组的完整人物列表

### Requirement: 支持保持打开的多选模式

系统 MUST 为对比区提供多选列表语义，并在选择或取消卡片后保持人物面板打开。

#### Scenario: 对比区选择人物

- **WHEN** 对比人物列表使用多选模式且用户点击一个可用选项
- **THEN** 系统切换该卡片的选择状态
- **AND** 列表保持打开并声明 `aria-multiselectable`

### Requirement: 在移动设备使用全屏面板

系统 MUST 在文档根元素具有 `mobile-device` 类时通过 Portal 将人物面板挂载到 `document.body`，覆盖完整视口且打开时不自动聚焦搜索框。

#### Scenario: 移动设备打开人物选择器

- **WHEN** 用户在移动布局中打开人物选择器
- **THEN** 系统显示全屏人物面板
- **AND** 搜索框不自动获得焦点
- **AND** 页面提供“完成”按钮用于关闭面板并恢复触发按钮焦点

### Requirement: 暴露可访问列表框语义

系统 MUST 为触发按钮、列表和选项提供展开状态、控件关联、listbox/option 角色和选择状态。

#### Scenario: 辅助技术读取打开的列表

- **WHEN** 人物选择面板处于打开状态
- **THEN** 触发按钮声明 `aria-expanded=true` 并关联列表 ID
- **AND** 每个选项通过 `aria-selected` 表达当前选择状态
