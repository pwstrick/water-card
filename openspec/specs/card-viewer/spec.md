## Purpose

定义用户在单卡鉴赏区选择人物、查看资料、操作 Three.js 卡片、切换正反面、缩放和下载当前视图时的完整行为。

## Requirements

### Requirement: 提供默认鉴赏状态

系统 MUST 在首次进入鉴赏区时选择普卡卡组和 ID 为 `001` 的宋江卡。

#### Scenario: 首次打开页面

- **WHEN** 用户首次加载应用且尚未进行任何选择
- **THEN** 鉴赏区显示普卡宋江
- **AND** 人物资料与 3D 卡面均使用该卡片的数据

### Requirement: 切换卡组并解析当前卡号

系统 MUST 在用户切换卡组时保留当前卡片 ID，并在目标卡组没有该 ID 时展示目标卡组第一张卡。

#### Scenario: 目标卡组包含当前 ID

- **WHEN** 用户切换到包含当前卡片 ID 的卡组
- **THEN** 鉴赏区显示目标卡组中具有相同 ID 的卡片

#### Scenario: 目标卡组不包含当前 ID

- **WHEN** 用户切换到不包含当前卡片 ID 的卡组
- **THEN** 鉴赏区回退显示目标卡组的第一张卡

### Requirement: 循环切换当前卡组人物

系统 MUST 允许用户按当前卡组顺序切换上一位或下一位人物，并在到达首尾时循环。

#### Scenario: 从第一张切换上一位

- **WHEN** 当前卡片为卡组第一张且用户点击“上一位人物”
- **THEN** 系统选择该卡组最后一张卡

#### Scenario: 从最后一张切换下一位

- **WHEN** 当前卡片为卡组最后一张且用户点击“下一位人物”
- **THEN** 系统选择该卡组第一张卡

### Requirement: 展示人物和版本资料

系统 MUST 展示当前卡片的编号、卡组、版本、人物名、拼音名、人物介绍及与人物类型匹配的基础资料。

#### Scenario: 展示好汉资料

- **WHEN** 当前卡片不是恶人卡
- **THEN** 页面显示绰号和星号

#### Scenario: 展示恶人资料

- **WHEN** 当前卡片是恶人卡
- **THEN** 页面显示身份和系列
- **AND** 使用恶人对应的视觉徽章色调

### Requirement: 忠实渲染卡片正反面

系统 MUST 使用原始卡图和集中式裁切布局渲染带厚度的正反面卡片，不得额外叠加奖闪 Shader、反光 Mesh 或人工闪光效果。

#### Scenario: 显示任一卡组卡片

- **WHEN** 当前卡片纹理加载成功
- **THEN** Three.js 场景使用同一张原始纹理分别渲染正面和背面
- **AND** 卡组间的视觉差异完全来自原始图片素材和基础徽章样式

### Requirement: 换卡时复用 Three.js 场景

系统 MUST 在鉴赏组件生命周期内复用 WebGL renderer、相机和卡身结构，仅替换与当前图片相关的纹理、UV 几何体和材质。

#### Scenario: 用户连续切换人物

- **WHEN** 用户在鉴赏区选择另一张卡
- **THEN** 系统通过现有场景更新卡片资源
- **AND** 不重新创建 WebGL renderer

#### Scenario: 旧纹理晚于新纹理返回

- **WHEN** 快速换卡导致旧图片请求在新图片请求之后完成
- **THEN** 系统丢弃并释放旧纹理
- **AND** 当前场景继续显示最新选择的卡片

#### Scenario: 鉴赏组件销毁

- **WHEN** Three.js 鉴赏组件卸载
- **THEN** 系统停止动画并解除输入和尺寸监听
- **AND** 释放纹理、几何体、材质和 renderer

### Requirement: 支持拖动旋转和惯性

系统 MUST 在普通缩放状态下将单指或鼠标拖动解释为卡片旋转，并在拖动结束后按最后速度产生逐步衰减的惯性。

#### Scenario: 普通状态拖动卡片

- **WHEN** 用户按住并移动指针
- **THEN** 卡片根据横向和纵向位移旋转

#### Scenario: 结束旋转拖动

- **WHEN** 用户完成一次具有速度的旋转拖动
- **THEN** 卡片继续短暂旋转
- **AND** 旋转速度逐帧衰减至停止

### Requirement: 支持正反面快捷切换

系统 MUST 允许用户通过正反面按钮或双击卡片切换当前朝向，并选择最短旋转路径到达目标面。

#### Scenario: 点击背面按钮

- **WHEN** 当前显示正面且用户点击“背面”
- **THEN** 卡片沿最短路径旋转到 `180` 度

#### Scenario: 双击卡片

- **WHEN** 用户双击卡片画布
- **THEN** 系统在正面与背面之间切换

### Requirement: 支持缩放和放大模式

系统 MUST 支持滚轮、缩放按钮和双指捏合缩放，缩放范围约为 70% 至 560%，并在缩放超过 108% 时进入全屏放大模式。

#### Scenario: 进入放大模式

- **WHEN** 当前缩放比例超过 108%
- **THEN** 鉴赏区覆盖整个视口
- **AND** 显示移动/翻转模式切换和退出按钮

#### Scenario: 放大后移动卡片

- **WHEN** 放大模式的拖动方式为“移动”且用户拖动卡片
- **THEN** 系统平移卡片可视区域并限制最大偏移

#### Scenario: 放大后翻转卡片

- **WHEN** 放大模式的拖动方式为“翻转”且用户拖动卡片
- **THEN** 系统旋转卡片而不是平移

#### Scenario: 双指缩放并移动

- **WHEN** 用户使用两根手指改变间距和中心位置
- **THEN** 系统同时更新缩放比例和平移位置

#### Scenario: 退出放大模式

- **WHEN** 用户点击退出按钮或按下 Escape
- **THEN** 缩放恢复到 100% 且平移逐步回到中心
- **AND** 拖动方式恢复为“移动”
- **AND** 当前旋转角度保持不变

### Requirement: 支持非冲突的键盘快捷键

系统 MUST 在焦点不位于交互控件时支持方向键旋转、空格翻面、加减号缩放和 Escape 退出放大，并避免同时触发页面默认滚动。

#### Scenario: 使用方向键旋转

- **WHEN** 用户在非交互元素上按下左或右方向键
- **THEN** 卡片按对应方向旋转 30 度

#### Scenario: 焦点位于人物搜索框

- **WHEN** 用户在输入框、按钮、列表框、选项或标签控件内按下卡片快捷键
- **THEN** 鉴赏区不得响应此次快捷键

### Requirement: 下载当前卡片视图

系统 MUST 在支持下载的浏览器中将当前角度、缩放和平移状态下的 WebGL 画面导出为 PNG，并在 UC 浏览器中隐藏下载入口。

#### Scenario: 下载当前视图

- **WHEN** 用户点击下载按钮且渲染器仍有效
- **THEN** 系统使用临时 RenderTarget 导出当前画面
- **AND** 下载文件名包含人物名、可选版本名和三位角度值

#### Scenario: 使用 UC 浏览器

- **WHEN** 系统识别当前浏览器为 UC 浏览器
- **THEN** 鉴赏工具栏不显示下载按钮

### Requirement: 限制移动端渲染成本

系统 MUST 在移动设备上将 renderer pixel ratio 限制为 1.5，并将纹理 anisotropy 限制为 4。

#### Scenario: 在移动设备创建场景

- **WHEN** Three.js 鉴赏区在移动设备初始化
- **THEN** renderer pixel ratio 不超过 1.5
- **AND** 卡片纹理 anisotropy 不超过 4
